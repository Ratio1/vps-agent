# Incident Report: Cloud VPS 20 SSD 62.146.172.224 / Cap-27

## Recipient

Contabo Abuse Team

## Subject

Response to abuse notification alleging phishing-related misuse of Cloud VPS 20 SSD `62.146.172.224` / `Cap-27`.

## Report Date

2026-06-17

## Executive Summary

We investigated the abuse notification concerning Cloud VPS 20 SSD `62.146.172.224` / `Cap-27`.

The forwarded complaint alleged that the IP address `62.146.172.224` was being used as a rogue DNS server in a phishing-related attack against third-party internet users.

Based on the investigation performed on 2026-06-17, `Cap-27` did not, and does not, contain harmful or potentially harmful phishing-related elements within the scope of the complaint.

No evidence was found that the VPS:

- Operates as a public DNS resolver.
- Operates as a rogue DNS server.
- Redirects, blocks, or manipulates banking or legitimate service traffic.
- Hosts phishing websites or credential-harvesting content.
- Runs phishing-related mail or spam infrastructure.
- Exposes a phishing-related service on the reported IP address.

The reported IP address refuses DNS queries on port `53`. The VPS has no public DNS listener, no DNS server process, no DNS container exposure, and no firewall or NAT rule redirecting DNS traffic.

## Complaint Summary

The complaint stated that `62.146.172.224` was configured on compromised third-party routers as a DNS server and alleged that this DNS server was blocking or redirecting access to banking websites and legitimate services.

The complaint therefore implies that the VPS was operating a malicious DNS resolver or DNS redirection service.

## Investigation Findings

### 1. External DNS Reachability

External DNS tests were performed against `62.146.172.224`.

Findings:

- UDP DNS query to `62.146.172.224:53` was refused.
- TCP DNS query to `62.146.172.224:53` was refused.
- TCP port `53` was closed/refused.
- TCP port `22` was reachable and used as a control check.

Conclusion:

`62.146.172.224` is not reachable as a DNS resolver from the public internet.

### 2. Local DNS Listener Review

The VPS was checked for DNS listeners.

Findings:

- No listener exists on `0.0.0.0:53`.
- No listener exists on `62.146.172.224:53`.
- DNS-related listening sockets were limited to local system resolver loopback addresses:
  - `127.0.0.53:53`
  - `127.0.0.54:53`

Conclusion:

The VPS does not expose DNS service publicly. Local resolver bindings are normal operating-system resolver behavior and are not accessible as a public DNS service.

### 3. DNS Server Process Review

Running processes and services were reviewed for DNS server software.

No public DNS server process was identified. In particular, no active phishing-related DNS infrastructure was found for:

- BIND / named
- dnsmasq
- Unbound
- CoreDNS
- PowerDNS
- Pi-hole
- AdGuard DNS
- Similar public resolver services

Conclusion:

The VPS is not operating DNS server software capable of acting as the rogue DNS resolver alleged in the complaint.

### 4. Container DNS Exposure Review

Container networking was reviewed for DNS-related exposure.

Findings:

- No container port mapping exposes DNS.
- No container listener exists on port `53`.
- No container-based DNS resolver was identified.

Conclusion:

The VPS is not providing DNS service through container networking.

### 5. Firewall and NAT Review

Firewall and NAT rules were reviewed for DNS handling.

Findings:

- No DNS destination NAT rule was identified.
- No DNS source NAT rule was identified.
- No rule redirecting DNS traffic to another process or container was identified.

Conclusion:

There is no firewall or NAT configuration that would redirect DNS traffic for phishing-related purposes.

### 6. Direct Web Exposure on Reported IP

The reported IP address was checked for direct web exposure.

Findings:

- `http://62.146.172.224` did not serve a website.
- `https://62.146.172.224` did not serve a website.
- No phishing website was identified on the reported IP.
- No credential-harvesting page was identified on the reported IP.

Conclusion:

The reported IP is not directly hosting phishing web content.

### 7. Phishing Mail Infrastructure Review

The VPS was checked for common phishing-mail infrastructure.

Findings:

- No active mail server service relevant to phishing was identified.
- No postfix, exim, sendmail, or equivalent phishing-mail process was identified.
- No mail queue tooling was present.

Conclusion:

The VPS is not operating phishing-related mail infrastructure.

## Public Application Health Endpoint

## Determination

The investigation did not identify any harmful or potentially harmful phishing-related element on `62.146.172.224` / `Cap-27`.

The complaint evidence appears to show that a third-party router was configured with `62.146.172.224` as a DNS value. However, the VPS itself is not operating a DNS resolver and refuses DNS traffic. Therefore, the screenshot alone does not demonstrate that `Cap-27` hosted, performed, or enabled the alleged DNS-based phishing activity.

Based on the evidence collected:

- `Cap-27` did not, and does not, operate a rogue DNS server.
- `Cap-27` did not, and does not, host phishing content on the reported IP.
- `Cap-27` did not, and does not, provide phishing-related mail infrastructure.
- `Cap-27` did not, and does not, contain harmful or potentially harmful phishing-related elements within the investigated scope.

## Actions Taken

2. Tested public DNS reachability over UDP and TCP.
3. Reviewed local DNS listeners.
4. Reviewed DNS-related running processes and services.
5. Reviewed container DNS exposure.
6. Reviewed firewall and NAT rules for DNS redirection.
7. Reviewed direct HTTP/HTTPS exposure on the reported IP.
